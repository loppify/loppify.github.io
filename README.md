# Rostyslav Tarasov — Portfolio

A static portfolio written in HTML, CSS, and JavaScript. No build step or package installation is required.

## Run locally

Extract this ZIP, open a terminal in the extracted folder, and run:

```sh
python -m http.server 8000
```

Open http://localhost:8000 in your browser.

## Edit

- `index.html`: page content, project descriptions, and links.
- `assets/style.css`: layout, colors, typography, and responsive styles.
- `assets/main.js`: email copy button and footer year.
- `assets/Rostyslav_Tarasov_Backend_Resume.pdf`: downloadable resume.
- `assets/favicon.svg`: browser tab icon.

Fonts load from Google Fonts, with local sans-serif fallbacks.

## Hosting

Upload `index.html` and the complete `assets` directory together to a static web host. They are ready to place at the root of your existing portfolio repository. This archive does not modify your existing GitHub repository or its publishing settings.
