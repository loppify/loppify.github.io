What I built

UUID-based form endpoints, async database access, structured JSONB submissions, and Telegram integration. A server-rendered interface supports English, Ukrainian, and German.

What I’m learning

Following a request through validation, storage, and an external API. Flow tests mock Telegram; GitHub Actions runs tests and code checks.

What comes next

Delivery tracking and retries, safer destination setup, spam controls, and feedback from people with real forms. The MVP currently has no guaranteed delivery or file uploads.
